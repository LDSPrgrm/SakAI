# sakai_shared

Shared UI, theming, validators, and API client for the SakAI passenger + driver Flutter apps.

Consume from either app via:

```dart
import 'package:sakai_shared/sakai_shared.dart';
```

## Design System

See [`docs/design-system.md`](docs/design-system.md) for tokens, semantic colors, the component catalog, the screen skeleton, and do/don't rules.
